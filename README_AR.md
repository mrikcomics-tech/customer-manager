# تطبيق إدارة الزبائن والرحلات - PWA

هذه نسخة هاتفية تعمل كتطبيق ويب قابل للتثبيت (PWA)، ولا تحتاج Android Studio.

## التشغيل السريع

1. ارفع محتويات هذا المجلد إلى استضافة HTTPS ثابتة.
2. افتح الرابط من هاتف Android عبر Chrome.
3. من قائمة Chrome اختر "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق".
4. افتح الإعدادات داخل التطبيق.
5. ضع نفس SYNC_URL الموجود في برنامج الكمبيوتر.
6. ضع نفس SYNC_TOKEN.
7. اضغط حفظ ثم مزامنة.

## مهم

- التطبيق يستخدم localStorage للعمل دون اتصال.
- كل سجل يحصل على sync_id ثابت.
- عند التعديل يبقى sync_id نفسه.
- المزامنة تعتمد على updated_at لاختيار النسخة الأحدث.
- خادم Google Apps Script يجب أن يسمح بطلبات POST وأن يتعامل مع token/api_key.
- بما أن التطبيق يعمل من المتصفح، لا تضع في الكود مفتاحًا شديد الحساسية؛ SYNC_TOKEN هنا يعمل كرمز وصول للتطبيق.
- هذا المشروع لا يحتاج Android Studio.
